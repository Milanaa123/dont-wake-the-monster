# Don’t Wake the Monster! — локальная сборка для Windows Studio

Распакуйте архив целиком. В PowerShell из распакованного каталога запустите `./Open-Studio.ps1`. Скрипт копирует собственные меши, текстуру и звуки в отдельную папку установленной Roblox Studio и открывает локальный Place. Для установки Studio в Program Files понадобится право записи в её каталог content. При необходимости можно скопировать папку `content/dwtm_orchard_…` в `content` установленной версии Studio вручную и открыть `DontWakeTheMonster-Studio.rbxlx`. При обновлении Studio повторите копирование.

Войдите в официальное окно Roblox самостоятельно и нажмите Play. Разрешение на облачные сохранения для локальной проверки фермы не требуется. При отключённом DataStore доступны действия с начальными семенами. Покупки, для которых игра требует загруженный профиль, останутся закрыты.

В архиве лежат материалы для локального клиента Windows. Отдельная стандартная сборка Rojo содержит сжатую геометрию в ServerStorage. Она использует разрешённые разработчику AssetService API и при их недоступности сохраняет прежнее оформление. Загруженные автором модели в DWTM_ArtLibrary имеют приоритет. Файловые ссылки комплекта Studio предназначены для компьютера с установленным комплектом.
